# Attendance Percentage Calculator

## About
A beginner-friendly Java program to calculate
student attendance percentage.

## Features
- Counts attended classes.
- Counts absent classes.
- Calculates attendance percentage.
- Checks exam eligibility (75% required).

## Technologies Used
- Java
- Arrays
- For loop
- If-else conditions

## How to Run

javac AttendancePercentage.java

java AttendancePercentage
